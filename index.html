複製格式

本 App 完全在手機上辨識，不需要 API Key，也不會把圖片傳到任何伺服器。第一次辨識需下載約十幾 MB 的語言資料，之後會快取。手寫姓名 Tesseract 通常讀不準，所以會在上方顯示姓名區域的截圖，請對照後自行輸入。紀錄只存在這支手機的瀏覽器，清除網站資料或換手機會消失，請定期匯出 CSV。
